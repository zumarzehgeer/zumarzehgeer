## Selected projects

### [Waycast — Weather-Aware Truck Routing](https://github.com/zumarzehgeer/weather-aware-truck-routing-app)

A React/TypeScript and Django application built for a developer assessment. It compares routes using forecast weather at estimated arrival times, explains load-sensitive risk, and includes an explicitly synthetic demo.

[Try Waycast](https://weather-aware-truck-routing-app.onrender.com/) · [Architecture and engineering decisions](https://github.com/zumarzehgeer/weather-aware-truck-routing-app#architecture) · [Tests and validation](https://github.com/zumarzehgeer/weather-aware-truck-routing-app#verification)

### [Nimaaz Time Viewer](https://github.com/zumarzehgeer/nimaazTimeViewer)

A React/TypeScript prayer-time display with Firebase account settings, configurable adhan/iqamah times and a next-prayer countdown. Includes an isolated synthetic guest demo, shared schedule calculations, 14 unit cases, eleven browser checks and nine local Firestore rules/comparison cases. Account-emulator tests cover offline synchronization, account isolation and signup rollback/retry.

[Try the synthetic guest demo](https://nimaaz-time-viewer.vercel.app/?demo=1) · [Setup and screenshots](https://github.com/zumarzehgeer/nimaazTimeViewer#try-the-guest-demo-locally) · [Implementation and validation](https://github.com/zumarzehgeer/nimaazTimeViewer/blob/main/docs/VALIDATION.md)

### [Product Release API — Node.js and TypeScript](https://github.com/zumarzehgeer/api-design-v4)

An owner-scoped product, release and release-note API using Express, Prisma and PostgreSQL. Extended from Scott Moss's API Design with Node.js v4 coursework, with authentication, strict validation, indexed pagination and 17 real PostgreSQL integration cases. A two-account demo exercises the compiled server and checks cross-account isolation.

[Run the API and demo](https://github.com/zumarzehgeer/api-design-v4#evaluate-locally) · [API reference](https://github.com/zumarzehgeer/api-design-v4/blob/main/docs/API.md) · [Implementation and validation](https://github.com/zumarzehgeer/api-design-v4/pull/1)

All three showcase implementations are on their default branches. Waycast and Nimaaz offer synthetic demonstrations; the release API includes reproducible local setup and a two-account demo.
